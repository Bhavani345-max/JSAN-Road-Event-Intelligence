# 0059 — Twenty-three official feeds from the worldwide search

**Status:** 5 November 2026. Code local, tested, for the user to review. In
production each feed runs once its id is added to `OFFICIAL_FEEDS_SCHEDULED_SOURCES`
on the API service (a Railway change, after the user's go).

## Context

The user, 5 November 2026: "check for other sources i need atleast 100 active
working sources from all over the world". Production had 55 working sources.
The worldwide search of that day (`docs/data-sources/worldwide-sources-2026-11-05.md`)
found 27 keyless sources whose licences permit REI's commercial use; asked which to
build, the user chose the 23 strong ones ("23 strong sources (Recommended)").
Left for the user's decision: Hawaii DOT (dates generated by the feed), LMS BW
traffic messages and Tararua (no end dates), Montpellier (ODbL share-alike).

## Decision

Each feed is its own module in `backend/connectors/official/`, registered in
`connectors/registry.py` and listed on its country entry. All: tier 1, government
open data, `PERMITS_TESTING`, recorded as permitted with attribution (never as
settled: no legal review, decision 0009). Common rules, as for every official feed:

- Only what the source states: no invented names, times, positions or shapes.
  Date-only periods are whole local days; times without an offset are read in the
  source's own zone; a period with no stated start or end keeps none (and is shown
  as unconfirmed).
- Only events on the carriageway (decisions 0053, 0058): footway-only works,
  parking bans, no-hindrance works and similar are left out, each rule in the
  module's docstring.
- Personal data (applicants, staff, contacts, telephone numbers, e-mail addresses)
  is dropped before anything is stored.
- Every fixture is a real excerpt of 5 November 2026 with personal data replaced.

### United Kingdom and Luxembourg (`united-kingdom`, `luxembourg`)

| Source id | Publisher | Licence | 5 Nov: kept | Polling |
|---|---|---|---|---|
| `gb-national-highways-roadworks` | National Highways, planned roadworks on England's strategic roads (weekly XML) | Open Government Licence | 1,414 in a run (527 + 887) of 1,777 phases | 1440 min |
| `lu-cita-roadworks-datex2` | Administration des ponts et chaussées (CITA), current and future works (DATEX II 2.2) | CC0 1.0 | 259 stages in a run (154 + 105) | 60 min |

- **National Highways** publishes a new file each Monday; the connector takes the
  newest link on the www.data.gov.uk dataset page (else tries the last four Mondays'
  file names), never the CKAN API host (robots `Disallow: /`). Its positions are
  British National Grid: `connectors/official/osgb36.py` converts them (inverse
  Transverse Mercator on Airy 1830, then the Ordnance Survey's 7-parameter Helmert),
  tested against the Ordnance Survey guide's worked examples (Annexes B, C, D: within
  1 mm per step, 4.3 cm for the whole chain); its real accuracy is that of the
  Helmert step, up to about 3 m across Britain. Times are UK local time. Embargoes,
  off-network entries and abnormal-load movements are not road events and are left out.
- **CITA works** are the planned works programme on all national roads, with ends;
  REI's existing `lu-cita-datex2-v36` is live motorway events without ends. They
  share no ids; the same works can appear in both (5 of 12 works events of the 3.6
  feed lay within 150 m of a works stage in force here on 5 November), to be
  matched by REI's merge step by place and time. One record per works stage (a
  DATEX record id repeats within a stage), at the start point of its leading
  measure; no line is drawn between start and end points.
